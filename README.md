# Мизансцена

Приложение режиссёра: сценарий, режиссёрский сценарий и Shot Designer (план сцены сверху) в одном проекте.
Работает в браузере на компьютере и на телефоне. Зависимостей нет, нужен только Node.js.

## Запуск

Двойной щелчок по `Запустить.bat` или в терминале:

```bash
node server.js
```

Приложение откроется на http://localhost:5180. Адрес для телефона в той же сети Wi-Fi показан на странице проектов.
Сервер виден всем устройствам в этой сети и не спрашивает пароль, поэтому в чужих сетях его лучше не запускать.

## Где что лежит

- `server.js`: сервер, раздаёт приложение и сохраняет проекты.
- `public/`: приложение.
  - `app.js` переходы между экранами, список проектов, страница проекта;
  - `script.js` редактор сценария, Fountain, FDX, печать;
  - `director.js` режиссёрский сценарий;
  - `plan.js` Shot Designer;
  - `shapes.js` условные знаки и каталоги объектов и света;
  - `store.js` открытый проект и автосохранение, `storage.js` чтение и запись.
- `projects/*.json`: проекты, по файлу на проект. `projects/assets/` картинки. `projects/.trash/` удалённые проекты.
- `scenes/`: сцены первой версии приложения, больше не используются.

Файл проекта можно править руками или просить об этом Claude: открытое приложение подхватывает изменения без перезагрузки.

## Формат проекта

```jsonc
{
  "name": "Название",
  "script": { "blocks": [
    { "type": "scene", "text": "ИНТ. КУХНЯ. ВЕЧЕР", "id": "sc-kitchen" },   // id нужен только сценам
    { "type": "action", "text": "…" },
    { "type": "character", "text": "Анна" }, { "type": "paren", "text": "тихо" }, { "type": "dialogue", "text": "…" }
    // ещё: transition, title, note
  ] },
  "plans": [ { "id": "plan-kitchen", "name": "Кухня", "sceneId": "sc-kitchen", "note": "", "objects": [ /* см. ниже */ ] } ],
  "shots": [ {                       // кадры: общие для режиссёрского сценария и Shot Designer, порядок как в массиве
    "sceneId": "sc-kitchen", "planId": "plan-kitchen", "cameraId": "camA",
    "size": "Общий", "move": "Статика", "content": "Что в кадре",
    "note": "", "mode": "Вечер", "dur": "0:12", "chars": "", "props": "", "tech": "Штатив", "frame": "/assets/kadr.jpg"
  } ]
}
```

Объектив, свет и персонажи в режиссёрском сценарии подтягиваются из плана и камеры кадра.

### Объекты плана

Единица длины: метр. Ось X вправо, ось Y вниз. `rot` в градусах по часовой стрелке, 0 значит «смотрит вправо».
`id` у объектов можно не писать, приложение добавит сам.

```jsonc
{ "type": "wall", "x1": 0, "y1": 0, "x2": 5, "y2": 0, "thickness": 0.15 }
{ "type": "door", "x": 5, "y": 3.2, "rot": 90, "w": 0.9 }        // ставится поверх стены
{ "type": "window", "x": 2.5, "y": 0, "rot": 0, "w": 1.4 }
{ "type": "furniture", "kind": "table", "x": 2.7, "y": 2, "rot": 0, "w": 1.4, "h": 0.8, "label": "" }
{ "type": "character", "x": 1.7, "y": 2, "rot": 0, "name": "Анна", "color": "#D8492F" }
{ "type": "camera", "x": 3.3, "y": 3.5, "rot": 222, "name": "A", "lens": 35, "sensor": "s35" }
{ "type": "light", "kind": "soft", "x": 0.9, "y": 3.5, "rot": 305, "w": 0.9, "color": "#E9A21B", "label": "Рисующий" }
{ "type": "path", "ownerId": "id персонажа или камеры", "points": [[4.4, 3.2], [3.65, 2]] }
{ "type": "text", "x": 1, "y": 1, "text": "Заметка", "size": 0.3 }
{ "type": "image", "src": "/assets/foto.jpg", "x": 3, "y": 2, "rot": 0, "w": 6, "h": 4, "ratio": 0.667, "opacity": 0.6, "locked": true }
```

- `furniture.kind`
  - мебель: `table`, `round`, `chair`, `armchair`, `sofa`, `bed`, `cabinet`, `shelf`, `bar`, `piano`, `tv`, `rug`;
  - интерьер: `stove`, `sink`, `fridge`, `bath`, `toilet`, `stairs`, `column`, `fireplace`, `mirror`, `curtain`, `block`;
  - натура: `tree`, `bush`, `rock`, `fire`, `bench`, `lamp`, `fence`, `road`, `water`, `tent`, `car`, `truck`, `bike`;
  - техника: `track`, `dolly`, `crane`, `monitor`, `boom`, `haze`, `genny`; люди: `crowd`.
- `light.kind`: `fresnel`, `open`, `dedo`, `hmi`, `soft`, `panel`, `tube`, `china`, `ring`, `practical`, `sun`, `frame`, `bounce`, `flag`.
- `camera.sensor`: `s35`, `ff`, `mft`, `s16`.
- `shots.size`: Деталь, Крупный, Средний по пояс, Средний по колено, Общий, Дальний.
- `shots.move`: Статика, Панорама, Наезд или отъезд, Тележка, Стедикам, С рук, Кран, Слайдер, Пролёт.

### Поля для 3D

Все необязательные: `camera.height` (м, по умолчанию 1.5) и `camera.tilt` (градусы, вверх плюс), `light.height` (м), `character.height` (м, 1.75), у плана `wallHeight` (м, 2.7).
Дверь и окно вырезают проём в стене, если стоят на её линии. 3D-движок three.js лежит в `public/vendor`, интернет для него не нужен.

## Добавлено 11 ноября 2026

- Запуск отдельным окном: `Мизансцена.bat` (сервер свёрнут, приложение открывается окном Edge без адресной строки).
- Правая кнопка мыши на объекте в 2D и 3D открывает его настройки у курсора; на пустом месте плана показывает слои.
- Слои хранятся только на время сеанса и в файл не пишутся.
- Фазы движения: `plan.phases = [{ id, name, pos: { idОбъекта: { x, y, rot } } }]`, `plan.phase` номер текущей. Объекты плана всегда стоят как в текущей фазе; своя расстановка по фазам есть у персонажей и камер. У кадра есть `phaseId`.
- Инструмент «От руки»: линия становится стеной, замкнутая фигура на стене окном, чёрточка от стены дверью, кружок персонажем, прямоугольник столом. Камера от руки не распознаётся.
- Новые поля: `character.look` (`m1`–`m3`, `f1`–`f3`), `character.pose` (`stand`, `sit`), `light.off`, `light.power` (проценты), у солнца `elev` (высота над горизонтом, градусы). Световые приборы `practical` (торшер) и `desk` (настольная лампа).
- В 3D объекты перетаскиваются по полу мышью, колесо во время перетаскивания поворачивает; стены двигаются только на плане.

## Программа на компьютере

`Мизансцена.lnk` или `Мизансцена.bat` открывают приложение отдельной программой (Electron, лежит в `node_modules`). Оболочка описана в `desktop.js`: она запускает тот же сервер и открывает окно; F11 полный экран, F5 обновить. `Запустить.bat` по-прежнему открывает приложение в браузере. Люди в 3D берутся из `public/models` (см. README там), пока модель грузится, стоит манекен.

## Реалистичное 3D (12 ноября 2026)

- `public/assets3d`: мебель, фактуры пола, стен и земли и панорама неба с Poly Haven (CC0), список в `SOURCES.txt`. Модели подставляются вместо простых форм для видов из `FURN_MODELS` в `view3d.js`; пока модель грузится, стоит простая форма. Высота мебели берётся настоящая, по плану растягивается только площадь.
- Днём (включено солнце) фоном и источником отражений служит панорама неба, ночью сцена тёмная.
- «Фотокадр» в 3D-виде через камеру: честный просчёт света (three-gpu-pathtracer, `public/vendor`), 400 проходов, результат сохраняется в раскадровку выбранного кадра.
- Деревья остались простыми: бесплатные модели деревьев весят сотни мегабайт.

## Изменения 12 ноября 2026

- Shot Designer: правая кнопка по объекту открывает меню (движение к следующей и предыдущей фазе, включить свет, смотреть через камеру, дублировать, удалить); по пустой доске правая кнопка двигает доску. Фазы и слои открываются кнопками над доской. Фазы есть у всех объектов, стоящих точкой (люди, камеры, свет, предметы).
- Инструмент «Движение» убран: путь задаётся через фазы, пунктир показывает переход к соседней фазе и не мешает выбирать героев.
- Рисование кистью (объекты `stroke`: `points`, `color`, `width`) и ластик; «Стены от руки» — прежнее распознавание.
- Поля значений: надпись слева, справа окошко со стрелками ◀ ▶; стрелку можно зажать и вести мышь (медленно — тонко, резко — крупно).
- Свет в 3D: мягкость тени зависит от размера источника, у приборов с линзой настраивается луч (`beam`) с сохранением потока, `tilt` — наклон, `kelvin` — цветовая температура. Цвет стен плана `wallColor` (и `color` у отдельной стены), цвет пола `floorColor`; отражённый от стен свет зависит от их яркости.
- PDF сохраняется файлом без окна печати (в программе, через `preload.js`), Excel — настоящий .xlsx с оформлением (`public/xlsx.js`).
- Импорт сценария из Word (.docx), PDF (pdf.js в `public/vendor`) и Fountain/FDX: `public/importers.js`.

## Программа и обновления (с 18 ноября 2026)

- Проекты хранятся в `Документы/Мизансцена/projects` (на Mac `~/Documents/Мизансцена/projects`), отдельно от программы. При первом запуске новой версии из папки с исходниками старые проекты копируются туда сами.
- Установщик для Windows: `npm run dist:win`, результат `dist/Mizanscena-Setup-<версия>.exe`.
- Версия для Mac собирается на GitHub (на Windows собрать её нельзя): `.github/workflows/release.yml` собирает Windows и Mac по тегу и выкладывает их в Releases.
- Выпуск новой версии: поднять `version` в `package.json`, закоммитить, `git tag v<версия>` и `git push --follow-tags`. Установленные программы проверяют Releases при запуске и раз в 4 часа и предлагают обновиться. На Windows обновление скачивается и ставится само; на Mac без платной подписи Apple открывается страница загрузки.
- Подписи кода нет: при первом запуске Windows покажет «Windows защитила ваш компьютер» (Подробнее → Выполнить в любом случае), а Mac — что программа от неизвестного разработчика (правый щелчок по программе → Открыть).

## Тестовая версия

Запуск из папки с исходниками (`Мизансцена — тест.lnk` или `npm start`) — это тестовая версия: окно «Мизансцена — тест», оранжевая метка «Тест», порт 5190. Её можно держать открытой рядом с установленной программой (порт 5180); проекты у них общие. Обновления в тестовой версии не проверяются: правки видны сразу после перезапуска окна (F5).

## Подключение ИИ-помощника (MCP)

Программа сама работает как MCP-сервер: `http://localhost:<порт>/mcp` (Streamable HTTP, порт 5180, у тестовой версии 5190). Код в `mcp.js`.
Готовые настройки для Claude Code, Claude Desktop и Cursor показывает кнопка «Подключить ИИ» на экране проектов.

- Инструменты: `list_projects`, `get_project`, `create_project`, `get_screenplay`, `edit_screenplay`, `get_plan`, `create_plan`, `add_objects`, `update_objects`, `delete_objects`, `add_phase`, `get_shots`, `edit_shots`, `get_reference`.
- Видны локальные проекты и облачные, если в программе выполнен вход: программа передаёт серверу пропуск в облако (`Документы/Мизансцена/.cloud-session.json`). Облачная правка при конфликте повторяется на свежей версии.
- `mcp-stdio.js` — мост для клиентов, которые запускают сервер командой (Claude Desktop). Установленная программа запускает его сама собой: `Мизансцена.exe` с `ELECTRON_RUN_AS_NODE=1`; если программа закрыта, мост её открывает.
- MCP отвечает только запросам с этого компьютера и не принимает запросы со сторонних сайтов в браузере.
